# Zeon (Simple Discord Bot)


## Features of the Zeon:

- `!ping` - A simple command to check if the bot is working.
- `!weather` - Shows the current weather in the city of your choice.
- `!clear` - Deletes messages.
- `!cube` - A dice mini-game.
- `!pay` - You can top up your balance
- `!balance` - You can Check your balance

## How to Run the Bot

To run the bot, create a `.env` file and define a variable named `BOT_TOKEN`. Set its value to your Discord bot token.
